Podcasts: favourites, Mark finished, auto-download

Three things Audiobookshelf already keeps on the server that the TV can't reach yet. Nothing here is stored only on the TV: Favourites is an Audiobookshelf playlist you choose in Settings (the server keeps playlists per library and lets them hold episodes and books), so it shows in the web and phone apps too, and the TV never creates one unasked; Mark finished is the same progress flag the web app sets; auto-download is the show's own setting on the server. Invented titles throughout; frames are 1920×1080 scaled down.

0. Settings: choose the Favourites playlist (off until you do)

A new row in Settings → Playback, for the library you are in (the server keeps playlists per library, so each library has its own choice; the row names the library). The row shows the current choice; Center opens a side panel, like Speed and Sleep, with a scrolling list: None (the default), ＋ Create "Favourites" (makes it on the server and selects it), then your playlists by name with their item counts. Focus opens on the current choice; Center picks and closes. Until a playlist is chosen there is no heart anywhere and no Favourites shelf. If the chosen playlist is deleted on the server, the hearts go away and the row is back to None.

2. The show: finished episodes, and actions on a row

Finished episodes are dimmed with a tick, as the web app shows them. On a focused row, Right moves onto small round buttons: Mark finished (a tick; on a finished episode it reads "Mark unfinished") and, when a Favourites playlist is chosen, the heart. Center on the row itself still plays it. Nothing changes while you scroll the list with Up and Down; the buttons only appear on the focused row.

3. The show's Downloads panel

"Downloads" on the show opens a side panel, like Speed and Sleep, with the show's own auto-download settings as the server keeps them. Changes save as they are chosen. Shown only to a user the server lets change the library (an admin, or a user with update rights); others see the settings read-only, or not at all.

4. Home: a Favourites shelf

On Home of each library, after Continue Listening, when that library has a Favourites playlist chosen: what is in it, in the playlist's order, under the playlist's own name. An episode plays from where it was left; a book opens its screen. Empty Favourites shows no shelf.
