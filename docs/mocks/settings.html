Settings and Switch Library — as sections, not as other screens

Both are reached from the menu, so they read as sections — but each is a separate Activity that replaces the screen, and the rail disappears. Here they are drawn inside the rail, where the menu stays put and Back still means "up a level". Both also report through Toasts today: a small grey box at the bottom of a television, gone in two seconds.

1. Settings

Today: a title, two switches, a version line and a button. Here the same things are grouped boxes with the value on the right, so a row says what it is set to without being focused. The rail is still there, and Settings is highlighted in it.

2. Settings — the theme can mean "follow the device" again

Each choice shows what it looks like, so you are picking a picture rather than a word. The switch is a boolean, so once it is touched there is no way back to following the device — even though ThemeChoice.resolve already supports exactly that, and it is what a fresh install does. Three choices say what the code can already do.

What this changes in the code

  • Both become views inside MainScreen (`MainView.SETTINGS`, `MainView.SWITCH_LIBRARY`) rather than Activities, so the rail stays and Back keeps meaning "up a level". `SettingsActivity` and `LibrarySelectionActivity` then have no callers, like `StatsActivity` before them.
  • The theme becomes three choices. `ThemeChoice.resolve(chosen, systemIsDark)` already takes a null for "follow the device"; only the UI cannot say it. This is a behaviour change, so it wants its own tests.
  • Toasts go. The update check reports into the row that asked, and errors sit beside what failed.
  • Left alone: the players, item detail and search stay full-screen. A player with a menu rail beside it is worse, not better.
  • The previews are the point of the row: Rows-versus-Grid and the three themes are visual choices, so each option carries a thumbnail of itself. They are cheap - a few boxes in the app's own colours, no screenshots to keep up to date.
  • Not decided: whether Sign out belongs in Settings (as drawn) as well as in the rail, or only here.
