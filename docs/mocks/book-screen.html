Book screen and About: one layout (#134)

Option 1 was approved (#134) and is built for both the book screen and the player's About; option 2 is kept for the record. Today's panel takes just under half the screen. Its description box is about five lines tall, and the facts run one per line underneath, so it reads cramped. Both options below give the description most of the space, show the series as real covers with titles, and set the facts out as a two-column list. Same content and order as the approved design: description, series, facts, Mark finished. Back closes it either way.

1. About as its own screen (chosen, #134)

About replaces the player while it is open, over the same cover wash. The cover and title stay on the left so you know which book this is. The description gets a wide box about ten lines tall; Down scrolls it. Under it, the series and the facts sit side by side. Most room; the cost is that you no longer see the bars and times while reading.
