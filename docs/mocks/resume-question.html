"Continue from where?": a roomier question

Today's question is a plain dark box with one sentence. This version keeps the same rule (asked only when the server holds a newer position, more than 30 s away, that this TV did not write) and the same two answers, with focus on the newer position and Back meaning "stay". What changes: it names the device that played, shows both places on a small timeline, uses chapter names for books, and sits over the player in the player's own style.

1. A book, listened to on a phone

The latest listening session names the device ("iPhone", "Audiobookshelf Web"…), so the question can say where. The timeline shows the gap at a glance; the buttons carry the chapter as well as the time.

2. An episode, changed elsewhere with no session

When the newer position came without a listening session (an edit in the web app, or an app that only saves progress), there is no device to name, so it says "elsewhere". Episodes have no chapters, so the buttons carry times.
