Updates: a question over Home, not a page

When a newer release is published, the app asks once on launch, in a small dialog over Home: "New version! Version v0.1.1 found. Update?", with Ignore, No and Yes. Yes downloads it in the same dialog with a progress bar, then hands over to Android's own "install an update?" screen. No asks again on the next launch. Ignore never asks about that version again; the next release asks as usual, and Settings → Check for updates still offers an ignored version. The full-screen update page and its "Later" (a one-day snooze) go.

1. On launch, when a newer release exists

Focus starts on No, so a stray OK press does nothing harmful. Right moves to Yes. Back means No.

3. Android takes over

Once the download is checked against the published checksum, Android's own installer asks to install the update; existing data stays. This screen belongs to Android, not to the app.
